## 🧠 Overview

QuantEdge is designed as a real-world trading simulation system that mimics core functionalities of stock trading platforms. It provides a seamless experience for users to interact with a virtual market environment, manage funds, and analyze portfolio performance.

The system follows a modular architecture separating frontend, backend, and dashboard services for scalability and maintainability.

---

## 🏗️ System Architecture

- **Frontend (React.js)** → User interface for trading operations and portfolio interaction  
- **Backend (Node.js + Express.js)** → REST APIs for authentication, trade execution, and data handling  
- **Dashboard Module** → Analytics layer for portfolio insights and fund tracking  
- **Database (MongoDB)** → Persistent storage for users, orders, and transactions
